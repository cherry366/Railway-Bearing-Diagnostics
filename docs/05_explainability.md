# 05 三层可解释性

对应代码：`code/explainability/explain_three_levels.py`、`constraint_analysis.py`

诊断模型是 XGBoost + CTL-ABC，我们按"事前 → 迁移过程 → 事后"三层给出证据，
拼成一个完整的解释框架：

```
I_total = I_prior + I_transfer + I_post
I_prior    = { f_structure, f_feature, f_mechanism }    模型为什么天生可解释
I_transfer = { f_alignment, f_constraint, f_adaptation } 知识到底传过去没有
I_post     = { f_decision, f_confidence, f_validation }  这条诊断凭什么可信
```

---

## 1. 事前可解释性：结构透明 + 特征重要性

**结构透明**：XGBoost 是 K 棵决策树的加法模型，每个分裂节点都是"某特征 ≤ 某阈值"的
确定性规则，整条决策路径可以逐节点展开，不存在黑箱隐层。

**特征重要性量化**：对第 j 个特征，在全部 K 棵树的所有非叶节点上累加增益：

```
I_j = (1/K) Σ_k Σ_{t∈T_k} 1[v(t) = j] · G_t

G_t = 1/2 [ G_L²/(H_L+λ) + G_R²/(H_R+λ) - (G_L+G_R)²/(H_L+H_R+λ) ]
```

重要性最高的主成分与 `Load`、`position` 的独热项高度相关，说明模型确实在用"工况 + 故障
机理"的组合做判断，而不是单纯记住波形。对应载荷热力图见
`results/figures/target_pca/pca_loading_heatmap.png`。

## 2. 迁移过程可解释性：路径可见 + 约束可量化

**知识迁移路径（t-SNE）**：把源域与目标域的特征同时降到二维。左图源域 7 类形成清晰簇群；
右图目标域样本落在与源域同类簇相近的位置，说明迁移的是"故障共性"而不是某个域特有的分布。
对应论文图 23。

**约束机制量化**：

| 观测量 | 迁移前 | 迁移后 | 变化 |
|---|---|---|---|
| MMD（域差异） | 0.3055 | 0.2896 | **−5.2%** |
| 平均置信度 | 0.384 | 0.821 | **+113.5%** |
| 类别平衡约束违反 | 7.0 | < 0.04（第 2 轮起） | 收敛 |

三个量对应三件事：域差异真的缩小了、模型的判断真的变确定了、类别分布真的贴近源域先验。

> 口径说明：第 4 篇文档表 10 里的 "MMD 下降率 9.32% / 5.43%" 是各算法以自身首轮 MMD 为
> 基线的完整收敛统计；本节 5.2% 是约束机制分析中以 0.3055 为基线的单次对照。两者都在说明
> "迁移有效"，只是基线取法不同。

## 3. 事后可解释性：决策追溯 + 机理映射 + 置信度校准

**决策路径追溯**：对目标域样本 x_i，softmax 之前的得分是 K 棵树输出之和，再把每棵树的
路径展开成"特征-阈值-方向"三元组：

```
P(y_i = c | x_i) = softmax( Σ_k f_k(x_i) )_c
P_i^k = { (v_t, τ_t, d_t) : t ∈ path(x_i, T_k) }
```

由此可以回答"为什么判成外圈故障"——是哪几个主成分、在哪个阈值上越过了边界。

**故障机理映射**：以外圈为例，用物理量交叉验证模型输出：

```
Confidence_OR = ω1·A(f_BPFO) + ω2·R_periodic + ω3·E_impulse
```

即故障特征频率处幅值、周期性指标、冲击能量三项加权。若模型判 OR 但 `A(f_BPFO)` 没有
明显峰值，就说明这条诊断需要人工复核。

**置信度校准（ECE）**：

```
ECE = Σ_m (|B_m| / n) · |acc(B_m) - conf(B_m)|
```

把置信度分桶后比较"实际准确率"与"平均置信度"，衡量模型是否"过度自信"。

**可靠性结论**（16 个文件，阈值 >0.8 高 / 0.6–0.8 中 / <0.6 低）：

| 置信度区间 | 文件数 | 占比 | 文件 |
|---|---|---|---|
| 高 | 11 | 68.8% | B、C、D、E、F、G、H、J、N、O、P |
| 中 | 2 | 12.5% | I（0.911）、L（0.721）|
| 低 | 3 | 18.8% | A（0.546）、K（0.288）、M（0.484）|

> 上表为论文 7.4.3 小节的口径（I 被归入中置信度）。若严格按表 9 的数值与 >0.8 阈值统计，
> 则为 高 12（含 I）/ 中 1（L）/ 低 3 —— 两种口径只差一个边界样本，结论一致：绝大多数
> 诊断结果具有高可靠性，3 个低置信度文件需要人工复核。

## 4. 小结

| 层次 | 回答的问题 | 手段 | 量化证据 |
|---|---|---|---|
| 事前 | 模型本身能不能被看懂 | 树结构、特征重要性 | 重要性排序 + 载荷热力图 |
| 迁移过程 | 知识有没有真的传过去 | t-SNE、MMD、约束违反 | MMD −5.2%、置信度 +113.5% |
| 事后 | 这条结论凭什么信 | 决策路径、机理映射、ECE | 68.8% 高置信、3 个低置信待复核 |

这套框架不只给"标签"，还给"标签的依据"和"该不该信"，这也是工程上真正能落地的那部分。
