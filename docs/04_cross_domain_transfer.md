# 04 跨域迁移诊断

对应代码：`code/transfer/target_preprocess.py`、`utl_abc.py`、`ctl_abc.py`、`compare_utl_vs_ctl.py`

## 1. 目标域先"扩样"再对齐

目标域只有 16 条样本，直接推理没有统计意义。先按机理扩样：

| 项 | 源域 | 目标域 |
|---|---|---|
| 滑窗 | 窗口/步长由故障周期决定（自适应） | 窗口 **10000** 点，步长 **1000** 点（固定） |
| 特征 | 时域 + 频域 + 时频域 41 维 | 同一套 41 维 |
| 标准化 | StandardScaler | StandardScaler |
| 平衡 | SMOTE | 不做（标签未知） |
| 输出维度 | 13 | 13 |

16 文件 × 247 窗 = **3952** 个目标域窗口。目标域 13 维 PCA 累计方差 **99.9%**。

## 2. UTL-ABC：无约束迁移

以源域训练好的 XGBoost 为初始模型 `f_θ`，迭代做三件事：

**① 分布差异度量（MMD，RBF 核）**

```
MMD^2(Xs, Xt) = || (1/ns) Σ φ(xs_i) - (1/nt) Σ φ(xt_j) ||²_H
MMD = sqrt( 1/ns² Σ K(xs_i,xs_j) + 1/nt² Σ K(xt_i,xt_j) - 2/(ns·nt) Σ K(xs_i,xt_j) )
```

**② CORAL 协方差对齐**

```
min_A || C_s - A C_t A^T ||²_F
X_s^aligned = (X_s - μ_s) C_s^{-1/2} C_t^{1/2} + μ_t
```

**③ 置信度伪标签 + 动态阈值**

```
conf_i = max_k P(y_i = k | x_i; θ)
D_high = { (x_i, ŷ_i) : conf_i > τ }
w_i = 1.0 (源域样本) / conf_i (目标域高置信样本)
```

每一轮用 `D_sample(源域) ∪ D_high(目标域)` 重训 XGBoost；标签变化率 < 1% 时提前收敛；
若第 3 轮后高置信样本不足 30%，阈值按 `τ ← max(0.5, τ - 0.05)` 自适应下降。

**总损失**

```
L_total = L_cls + λ1·MMD + λ2·L_pseudo + λ3·||θ||²
```

**参数**

| T | ε | δ | λ1 | λ2 | λ3 | τ(0) |
|---|---|---|---|---|---|---|
| 50 | 0.15 | 1.0 | 0.3 | 0.5 | 0.1 | 0.7 |

**结果**：MMD 由 0.30 收敛到 **0.2962**，标签变化率第 10 轮归零，平均置信度由 0.38 升至 **0.853**。

## 3. CTL-ABC：加两条约束

在 UTL 的基础上加两个"物理上必须成立"的约束：

**类别平衡约束**（目标域预测分布应贴近源域先验）

```
|P(Y_t = k) - P(Y_s = k)| ≤ ε,  ∀k
V_balance = Σ_k max(0, |p_k^t - p_k^s| - ε)^2
```

**特征一致性约束**（同类故障在两个域的特征中心应接近）

```
|| μ_k^s - μ_k^t ||² ≤ δ,  ∀k
V_consistency = Σ_k max(0, ||μ_k^s - μ_k^t|| - δ)^2
```

**总损失**

```
L_total = L_cls + λ1·MMD + λ2·L_pseudo + α1·V_balance + α2·V_consistency
```

**参数**

| T | ε | δ | λ1 | λ2 | λ3 | α1 | α2 | τ |
|---|---|---|---|---|---|---|---|---|
| 50 | 0.15 | 1.0 | 0.3 | 0.5 | 0.5 | 1.0 | 0.5 | 0.7 |

**结果**：MMD 由 0.317 降至 **0.2886**；约束违反程度前 2 轮从 7.0 骤降到 ~0.9，最终稳定在
**1.17**（趋势线斜率 −0.0613）；平均置信度 **0.865**。

## 4. 两种算法对比

| 指标 | CTL-ABC | UTL-ABC | 优势 |
|---|---|---|---|
| 最终 MMD | **0.2886** | 0.2962 | CTL |
| 平均置信度 | **0.865** | 0.853 | CTL |
| 最高置信度 | **0.992** | 0.991 | CTL |
| 置信度标准差 | **0.281** | 0.290 | CTL |
| 迭代次数 | 30 | 30 | — |
| MMD 下降率 | **9.32%** | 5.43% | CTL |
| 最终约束违反 | **1.1667** | — | CTL |

两算法逐窗口预测的**一致率 92.7%**。不一致时 CTL 的置信度明显更低——说明 CTL 在自己
"拿不准"时会诚实地给出低分，而 UTL 仍保持高置信度，容易误导使用者。

**因此最终选用 CTL-ABC** 作为目标域诊断模型。

> 置信度差异 ≤ 0.03（对照见 `results/README.md`）。

**关于随机性**：算法每轮从源域随机抽样重训，属于随机算法。仓库已在 `code/config.py` 固定
`RANDOM_SEED = 42`，同环境多次运行结果一致；但换种子复跑会得到另一条收敛轨迹：

- 9 个文件（B、D、E、F、G、H、J、O、P）的标签与可靠性等级在复跑中保持不变；
- 7 个边界文件（A、C、I、K、L、M、N）置信度落在 0.25–0.9，复跑时可能在 DE-B / DE-OR /
  FE-B 之间漂移，因此逐类占比会波动（例如某次复跑 DE-B 只有 4 个文件、DE-OR 升到 10 个）；
- 整体指标稳定：最终 MMD 落在 0.29–0.30，平均置信度 0.79–0.87。

上表与论文数值为成稿那一次运行的结果，复跑出现不同的边界结论属于算法随机性而非代码错误。
